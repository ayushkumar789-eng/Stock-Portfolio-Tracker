# 📊 Stock Portfolio Tracker

A simple Python-based project that helps users track their stock investments and calculate the total portfolio value.

## 🚀 Features
- Add stock names and quantities
- Uses predefined stock prices (hardcoded dictionary)
- Calculates total investment value
- Option to save results in a `.txt` file

## 🛠️ Technologies Used
- Python
- Basic Concepts:
  - Dictionary
  - User Input/Output
  - Arithmetic Operations
  - File Handling

## 📂 Project Structure

stock-portfolio-tracker/
│── stock_tracker.py     # Main Python script
│── portfolio.txt        # Saved portfolio (generated file)
